# Project Brief: Homs Student Union Media Guide (الدليل الإعلامي الموحد)

## Overview
Interactive web application and reference guide for the Media Department of the Student Union at Homs University (اتحاد الطلبة بجامعة حمص – القسم الإعلامي).

## Core Goals
- Present the comprehensive media guide (11 organizational sections) in an interactive, accessible web interface.
- Standardize media production, documentation, design, and publishing workflows across university bodies and institutes.
- Provide searchable, structured, and standalone documentation views.
